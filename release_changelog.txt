## Friendly Contacts 3.0.0-alpha.21

**Passwords and API keys are kept in Obsidian's keychain, no longer in data.json.**

- The password or API key of an address book is saved in Obsidian's keychain (**Settings → Keychain**): encrypted by your system, for this vault on this device, outside the vault. File sync, git and backups of the vault no longer carry it.
- **Type your password again** after updating. A password an earlier version saved in data.json is not used and is taken out of the file.
- On each device, type the password once: the keychain is not synced.
- Needs Obsidian 1.11.4 or later.
